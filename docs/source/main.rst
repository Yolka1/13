Основная программа
==================

Модуль ``main`` демонстрирует работу программы.

В программе выполняются:

* чтение FASTA-файла;
* получение последовательностей;
* вывод заголовка;
* вывод последовательности;
* вывод её длины;
* вывод уникального алфавита;
* определение типа последовательности.
