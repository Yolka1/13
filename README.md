FASTA Sequence Reader
=====================

Проект для чтения и анализа биологических последовательностей
в формате FASTA.

Описание
--------

Проект реализует два основных класса:

* Seq — хранение и анализ отдельной биологической последовательности;
* FastaReader — чтение FASTA-файлов по отдельным записям.

Класс Seq позволяет:

* получить последовательность;
* получить заголовок FASTA-записи;
* определить длину последовательности;
* определить уникальный алфавит;
* определить тип последовательности.

Класс FastaReader читает FASTA-файл с использованием генератора,
что позволяет работать с большими файлами без загрузки всего файла
в память.

Установка
---------

Для работы проекта необходим Python 3.

Рекомендуется использовать виртуальное окружение:

    python3 -m venv .venv

Активация виртуального окружения:

    source .venv/bin/activate

Запуск
------

Перейдите в каталог проекта:

    cd 13-2

Запустите демонстрационную программу:

    python3 main.py

Документация
------------

Документация проекта создана с использованием Sphinx.

Для сборки HTML-документации:

    cd docs
    make html

Готовые HTML-файлы находятся в:

    docs/build/html/
